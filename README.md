# 不到 100 块，我搓了一栋「赛博自建房」🏠

> 伍尔夫说，女人要拥有金钱和一间属于自己的房间——
> 我花不到 100 块，亲手搓了一栋**能听人话、会看家、能联网、还会自动报警**的
> ESP32 赛博自建房，把它装进了我的赛博小空间。

一块 **ESP32-S3** 开发板，配上总价不到 100 块的传感器模块：
喊一声「**你好小智**」，开灯、开风扇、问温度、查烟雾，都像吩咐朋友一样自然；
人在外面，微信小程序就是这栋房的远程钥匙；
烟雾、火焰、高温、高湿来了，它自己报警、自己开风扇。
这栋房不用多大——它是我一个人的赛博小空间。

本仓库是这栋房的**完整固件源码与搭建说明**（Arduino / PlatformIO 工程），
包含 **8 个独立功能模块 + 1 套完整系统**，可以一块一块点亮，也可以一步到位。
欢迎复刻，欢迎改造成你自己的赛博小空间 ✨

## 这栋房有什么

| 能力 | 说明 |
|---|---|
| 🎙️ 会听人话的赛博管家 | 唤醒词「你好小智」：语音开关灯/风扇/蜂鸣器，语音查询温湿度、烟雾、火焰、雨水、人体，语音调音量 |
| 📱 随身携带的远程钥匙 | 微信小程序「维控设备大师」远程开关设备、查看全部传感器实时数据、滑块调音量，设备执行后回传真实状态 |
| 👁️ 一屋子的赛博五感 | DHT11 温湿度、MQ-2 烟雾、火焰、雨水、人体红外 PIR 五路传感器实时监测，约每秒上报 |
| 🚨 会自己报警的安全卫士 | 烟雾→风扇+蜂鸣器自动开工；火焰→蜂鸣器拉响；高温/高湿→风扇自动启动。**报警优先，手动不打架** |
| 🖥️ 看得见的仪表盘 | 本地 OLED 实时显示环境数据，火焰/烟雾自动切报警页；小程序同屏同步 |

## 智能联动关系（完整系统）

| 检测结果 | 风扇 | 蜂鸣器 | 界面提示 |
|---|---|---|---|
| MQ-2 烟雾异常（预热完成后 ≥1800） | 自动开启 | 自动开启 | 烟雾报警 |
| 检测到火焰 | 不单独触发 | 自动开启 | 火焰报警 |
| 温度 ≥35℃（高温） | 自动开启 | 不触发 | 温度较高 |
| 湿度 ≥70%（高湿） | 自动开启 | 不触发 | 湿度较高 |
| 检测到雨水 | 不触发 | 不触发 | 检测到雨水 |
| 检测到人体活动 | 不触发 | 不触发 | 检测到人 |

阈值全部带**回差**（触发值/恢复值分离），传感器不会在临界值附近反复横跳：

| 项目 | 触发 | 恢复 | 代码里的宏（`src/m09_smart_house/main.cpp`） |
|---|---|---|---|
| 高温 | ≥35℃ | ≤33℃ | `TEMP_HIGH_ON / TEMP_HIGH_OFF` |
| 高湿 | ≥70% | ≤68% | `HUMI_HIGH_ON / HUMI_HIGH_OFF` |
| 烟雾 | ≥1800 | ≤1400 | `MQ2_ON / MQ2_OFF`（上电预热 120 秒后才允许触发）|
| 雨水 | ≤2000 | ≥2300 | `RAIN_ON / RAIN_OFF`（数值低=湿润）|

## 快速开始

### 1. 环境

[VS Code](https://code.visualstudio.com/) + [PlatformIO IDE 插件](https://platformio.org/install/ide?install=vscode)，打开本工程。

### 2. 填 WiFi

打开 `include/house_config.h`，改成你的 **2.4GHz** WiFi（ESP32 不支持 5GHz）：

```cpp
#define WIFI_SSID      "wcmgc"       // ← 你的 WiFi 名称
#define WIFI_PASSWORD  "12344321"    // ← 你的 WiFi 密码
```

### 3. 选模块，编译上传

想先点亮哪个模块就烧哪个。两种方式任选：

- 改 `platformio.ini` 顶部的 `default_envs` 为模块名，然后 PlatformIO 一键编译上传；
- 命令行：

```bash
pio run -e m01_led -t upload          # 灯光模块
pio run -e m09_smart_house -t upload  # 完整系统
```

上传后打开串口监视器（**115200**），复位开发板，记下串口打印的 **MAC 地址**（绑小程序用）。
首次启动固件会把「你好小智」唤醒模型解压到 model 分区，稍等片刻属正常。

### 4. 配置小程序（约 2 分钟）

1. 微信搜索小程序 **「维控设备大师」**，注册登录；
2. **添加设备**（名字随意，比如“赛博自建房”）；
3. 设备 **设置页 → 布局 JSON**：置空后粘贴 `miniprogram-layouts/` 里对应模块的 `.txt` 全部内容，保存；
4. 设置页填入串口读到的 **MAC 地址**；完整系统还需开启 **实时同步** 和 **AI 语音通话**；
5. 返回设备页 **连接设备**，显示“设备已连接”即可开玩。

### 5. 开口

> 「你好小智」→（听到应答后）→「打开灯」「关闭风扇」「现在温度是多少」
> 「有没有检测到火焰」「外面有雨吗」「家里有人吗」「把音量设置成 80」

## 常见问题

- **小程序显示设备离线**：查 WiFi 名称密码、是否 2.4GHz、串口里 MQTT 是否连上、绑定的 MAC 是否与串口一致。
- **AI 唤不醒/没声音**：查小程序是否开启 AI 语音、麦克风（35/36/37）与功放（48/47/21）接线、音量是否为 0；唤醒词清晰说「你好小智」。
- **按键没反应**：本套件按键按下为高电平；你的模块若相反，把 `house_config.h` 的 `BUTTON_DOWN_LEVEL` 改成 `LOW`。
- **DHT11 读不到数**：查 DATA 是否接 GPIO16 与共地；上电稳定 1~2 秒后再看，读取失败程序会保留上一次有效值。
- **MQ2 上电就报警**：MQ2 需要预热。完整系统内置 120 秒预热期，预热完成前不会触发烟雾报警；阈值按现场正常空气的稳定读数调整。
- **火焰/雨水读数和我对不上**：不同模块、供电、环境都会改变原始值，先实测再改阈值宏，别照搬我的数值。
